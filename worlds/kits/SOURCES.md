# Model kits

Ready-made 3D models that worlds can use with `<v-model>`. Every kit here is **CC0 (public domain)**: free to use, change and redistribute, with no attribution required. Each folder keeps the kit's own `License.txt`. Only the glTF/GLB models and their textures were copied in; the other formats and preview images were left out. The rule for anything from outside the project is in #38; the decision to use these kits is #65.
